# SYSTEM ROLE & ULTIMATE PIPELINE OBJECTIVE
You are an Expert Full-Stack Developer and Database Architect. Your task is to build a complete 3-Tier Web Application utilizing Flask (Backend), Supabase/PostgreSQL (Database), and Vanilla HTML/CSS/JS with Leaflet.js (Frontend).

**CRITICAL CONSTRAINT:** Build a NORMAL, TRADITIONAL WEB SITE. DO NOT use Streamlit. This is a standard Flask web app.

We are building a "Company Intelligence & Mapping Platform" with a strictly defined Data Pipeline across 3 Databases (Supabase Tables) and 3 UI Pages:

1. **The Search Page (`/search`):** Scrapes NEW companies. Data lands in `search_db`. Displayed as rows. Hovering over a row shows a floating pop-up card with a map. 
2. **The Matrix Hub (`/matrix`):** Data is migrated here from Search. Lands in `matrix_db`. Displayed as a Grid of Cards. Hovering scales the card up. DeepSeek AI enriches this data.
3. **The Global Map (`/` - index):** The main public view. Data is migrated here from Matrix after enrichment. Lands in `global_db`. Displayed as a massive, full-screen Leaflet map showing all finalized companies.

# 1. SUPABASE DATABASE SCHEMA (PostgreSQL)
Create the following 3 tables using Supabase (use `JSONB` for categories to avoid complex joins):

```sql
-- 1. Temporary Scraped Data
CREATE TABLE search_db (
    id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
    name TEXT NOT NULL,
    location_string TEXT,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 2. Enrichment Hub (Matrix)
CREATE TABLE matrix_db (
    id UUID PRIMARY KEY, -- Inherited from search_db
    name TEXT NOT NULL,
    location_string TEXT,
    lat DECIMAL(10, 8),
    lng DECIMAL(11, 8),
    email TEXT,
    phone TEXT,
    ai_status TEXT DEFAULT 'pending'
);

-- 3. The Final Global Site Database
CREATE TABLE global_db (
    id UUID PRIMARY KEY,
    name TEXT NOT NULL,
    location_string TEXT,
    lat DECIMAL(10, 8),
    lng DECIMAL(11, 8),
    email TEXT,
    phone TEXT,
    main_categories JSONB,
    sub_categories JSONB
);
