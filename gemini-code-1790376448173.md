You are an Expert Full-Stack Developer and Database Architect. Your task is to build a complete, custom Dual-Page web application utilizing Flask (Backend), MySQL (Database), and Vanilla HTML/CSS/JS with Leaflet.js (Frontend).

**CRITICAL CONSTRAINT:** Build a NORMAL, TRADITIONAL WEB SITE with a custom HTML/CSS UI. DO NOT use Streamlit, do NOT use external dashboard frameworks, and DO NOT reference "OBSIDIAN". This is a standard Flask web app.

2. **Matrix Hub (`matrix.html`):** Displays saved companies as a Grid of Cards. Hovering scales the card up. An AI script enriches these cards with missing emails/phones.

# 1. DATABASE SCHEMA (MySQL)
You MUST use this exact normalized structure:
```sql
CREATE TABLE companies (
    company_id VARCHAR(50) PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    location_string VARCHAR(255),
    latitude DECIMAL(10, 8),
    longitude DECIMAL(11, 8),
    is_matrix BOOLEAN DEFAULT FALSE,
    email VARCHAR(255),
    phone VARCHAR(255),
    ai_status VARCHAR(50) DEFAULT 'pending'
);

CREATE TABLE categories (
    category_id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(150) UNIQUE NOT NULL,
    type ENUM('MAIN', 'SUB') NOT NULL
);

CREATE TABLE company_categories (
    company_id VARCHAR(50),
    category_id INT,
    PRIMARY KEY (company_id, category_id),
    FOREIGN KEY (company_id) REFERENCES companies(company_id) ON DELETE CASCADE,
    FOREIGN KEY (category_id) REFERENCES categories(category_id) ON DELETE CASCADE
);
